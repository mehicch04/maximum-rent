UZROK (moja greška, ista vrsta kao ranije)
------------------------------------------
Ta dva modula i fontovi postojali su samo u mojoj radnoj kopiji. Kad sam
prošli put provjeravao, vidio sam ih kod sebe i zaključio da već postoje u
projektu, pa sam poslao samo izmjene u komponenti koja ih poziva.

Nisu bili ni u jednom zipu, pa ih tvoj projekat nikad nije ni dobio.

ŠTA JE U OVOM ZIPU
------------------
  components/admin/handover/generate-pdf.ts    PDF ugovor (jsPDF)
  components/admin/handover/generate-docx.ts   Word ugovor (docx)
  components/admin/handover/contract-data.ts   zajednički sadržaj oba
  public/fonts/contract-regular.ttf            font
  public/fonts/contract-bold.ttf               font

FONTOVI SU OBAVEZNI
-------------------
Nisu ukras. Ugrađeni fontovi u PDF-u pokrivaju samo zapadnu latinicu, pa bez
ovih Č, ć i đ nestaju iz dokumenta: "oštećenje" se ispiše kao "ošteenje", a
"Čitluk" kao "itluk".

Fontovi se učitavaju iz public/fonts u trenutku generisanja i pamte, pa ne
opterećuju veličinu sajta.

Provjereno s ovim fontovima:
    Čitluk, oštećenje, đak, Žepče, Ljubuški   -> ispravno

KAKO SAM PROVJERIO OVAJ PUT
---------------------------
Prošao sam sve uvoze u handover folderu i uporedio ih s onim što stvarno
postoji. Vercelov ispis imenuje tačno ova dva modula kao nedostajuća, a
sve ostalo se razriješilo, što znači da je ostatak već kod tebe.

KORACI
------
1. Raspakuj preko root-a projekta.
   (dodaje i folder public/fonts s dvije datoteke)
2. npm install       ako nisi nakon prošlog zipa
3. npm run build     <-- mora proći
4. npm run dev -> /admin/ugovori
   - preuzmi PDF i otvori ga
   - provjeri č, ć, š, ž, đ u tekstu
   - probaj i Word verziju

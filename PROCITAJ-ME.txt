MAXIMUM RENT A CAR — ikonica vrata AUTA umjesto kucnih vrata
============================================================

STA JE URADJENO
---------------
lucide nema ikonicu automobilskih vrata (DoorOpen izgleda kao kucna vrata).
Napravljena je custom ikonica vrata AUTA (components/ui/CarDoorIcon.tsx) u istom
stroke-stilu kao ostale ikonice na kartici, pa se uklapa. CarCard je sada
koristi za broj vrata umjesto DoorOpen.

FAJLOVI
-------
  components/ui/CarDoorIcon.tsx     (NOVO — ikonica vrata auta)
  components/fleet/CarCard.tsx      (koristi CarDoorIcon)
  components/ui/WhatsAppIcon.tsx    (zavisnost CarCard-a)

VAZNO
-----
Nisam mogao vizuelno provjeriti izgled ikonice u ovoj sesiji (alat za prikaz
slika je bio u kvaru). Molim te baci pogled u "npm run dev" na /vozila. Ako
ti nesto ne stima (npr. deblji stroke, veci prozor, jasnija kvaka), javi pa
podesim -- geometrija je u jednom malom SVG-u, lako se stela.

KORACI
------
1. Raspakuj preko root-a.
2. npm run dev -> /vozila: provjeri ikonicu vrata na kartici.
3. git add . && git commit -m "feat(card): ikonica vrata auta umjesto kucnih vrata" && git push

MAXIMUM RENT A CAR — desktop payload (video se ne skida dvaput)
==============================================================

PRVO, ISKRENO: sve stavke sa tvog screenshota su "Unscored" -> PageSpeed sam
pise "These numbers don't directly affect the Performance score". Tvoj desktop
Performance je skoro sigurno vec 99-100. Znaci ovo NE obara ocjenu, samo su
dijagnostika. Ali jedna od njih (payload) ima realnog smisla pa je rjesavam.

STA JE BILO
-----------
Na desktopu su se ucitavala OBA video fajla: /hero.mp4 (2.1MB) I /hero.webm
(1.5MB) = ~3.6MB. Video element je imao dva <source> (webm + mp4), a umjesto
da uzme jedan, browser je povlacio oba. Zbog toga je ukupan payload bio 4.3MB.

RJESENJE  [components/home/Hero.tsx]
--------
Sada se bira SAMO JEDAN izvor, feature-detekcijom:
  - browseri koji podrzavaju webm (Chrome, Edge, Firefox, moderni Safari) ->
    ucitavaju samo hero.webm (~1.5MB)
  - stariji (bez webm-a) -> fallback na hero.mp4
Nikad se ne skidaju oba.

Efekat:
  - Desktop payload ~4.3MB -> ~2.2MB.
  - Posto je Lighthouse prag za "enormous payloads" oko 3MB, taj flag bi trebao
    NESTATI.
  - Mobitel je i dalje samo poster (bez videa) kao i prije.

STA OSTAJE (i dalje ne vrijedi juriti — sve "Unscored")
-------------------------------------------------------
- "Reduce unused JavaScript 23 KiB": Next/next-intl/framer kod. Ne moze se
  smanjiti bez skidanja funkcionalnosti.
- "Non-composited animations (2)" i "Long main-thread tasks (2)": sitni
  frameworkski efekti/hidracija. Ne uticu na ocjenu.

FAJL
----
  components/home/Hero.tsx

KORACI
------
1. Raspakuj preko root-a.
2. npm run dev -> desktop: u DevTools Network otvori naslovnu, provjeri da se
   ucitava SAMO hero.webm (ne i hero.mp4).
3. git add . && git commit -m "perf(desktop): jedan video izvor (webm|mp4), pola manji payload" && git push
4. Ponovo PageSpeed (desktop) -> "enormous payloads" bi trebao nestati.

Napomena: alat za prikaz slika mi je u ovoj sesiji u kvaru pa nisam vizuelno
provjerio, ali TS je cist. Baci pogled da video na desktopu i dalje radi
(pusta se poster pa video).

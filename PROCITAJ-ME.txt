MAXIMUM RENT A CAR — currency prekidac kao clean dropdown
=========================================================

STA JE PROMIJENJENO  [components/currency/CurrencySwitch.tsx]
-------------------
Umjesto crvenog KM/€ pill-a koji je previse "bo o oci", sada je suptilan
dropdown:
  - Trigger: malo dugme sa okvirom koje pokazuje SAMO trenutnu valutu (KM ili €)
    + strelica. Bez crvenog fila -> smireno, ne bode oci.
  - Klik otvara mali meni: "KM  Marka" i "€  Euro". Aktivna opcija je oznacena
    (blagi brand tint + kvacica).
  - Zatvara se klikom vani, tipkom Escape, ili odabirom.
  - Vidljivo je i dalje (nije sakriveno), samo urednije.

Pristupacnost: aria-haspopup / aria-expanded / role=listbox/option, Escape.
Koristi tvoje postojece tokene (border, surface, surface-muted, brand-strong,
shadow-card) pa se uklapa u light i dark temu.

Samo JEDAN fajl je promijenjen. Navbar ga vec koristi, nista drugo ne treba.

KORACI
------
1. Raspakuj preko root-a (prepisi CurrencySwitch.tsx).
2. npm run dev -> u navbaru klikni valutu: otvara se cist dropdown.
3. git add . && git commit -m "ui: currency kao clean dropdown umjesto pill-a" && git push

Napomena: alat za prikaz slika mi je u ovoj sesiji u kvaru pa nisam mogao
vizuelno provjeriti. TS je cist. Baci pogled da dropdown lijepo sjedi (posebno
poravnanje desno i na mobitelu). Ako zelis da trigger umjesto "KM" pokazuje
npr. "KM ▾" krupnije, ili da doda i puni naziv, lako se stela.

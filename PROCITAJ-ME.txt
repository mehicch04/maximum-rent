MAXIMUM RENT A CAR — dvije valute (KM/€), BEZ admin opcije
==========================================================

FINALNO STANJE (po tvom zahtjevu):
  - Posjetilac ima prekidac KM / € u vrhu sajta i sve cijene se preracunavaju
    (fiksni kurs 1 EUR = 1.95583 KM, zaokruzeno).
  - Primarna valuta je MARKA (default). Opcija za mijenjanje valute u admin
    panelu je UKLONJENA.
  - Nema nikakve postavke u bazi -> NEMA prisma db push.

Kad pozelis promijeniti primarnu valutu (npr. da default bude €), javi pa
zamijenim jednu liniju.

STA JE U ZIP-u (samodovoljno)
-----------------------------
  lib/currency.ts                              (kurs/konverzija/format)
  components/currency/CurrencyProvider.tsx     (default = "BAM")
  components/currency/CurrencySwitch.tsx       (KM/€ prekidac)
  components/currency/Price.tsx
  components/fleet/CarCard.tsx                 (cijena kroz <Price/>)
  components/layout/Navbar.tsx                 (prekidac u traci)
  app/[locale]/layout.tsx                      (default valuta "BAM", bez baze)
  components/admin/AdminNav.tsx                (BEZ taba "Postavke")
  components/ui/WhatsAppIcon.tsx, CarDoorIcon.tsx  (zavisnosti CarCard-a)

*** AKO SI RANIJE PRIMIJENIO PROSLI (dual-currency) ZIP, OBRISI OVE FAJLOVE ***
(zip ih ne moze obrisati sam):
  app/admin/postavke/page.tsx
  app/admin/postavke/actions.ts
  lib/settings.ts
Ta tri fajla su bila admin opcija koju uklanjamo. Idu zajedno.
(Model "Setting" u prisma/schema.prisma, ako ga imas, moze ostati -- prazna
neiskoristena tabela, bezopasno. Ne treba db push.)

Ako NISI ranije primjenjivao dual-currency zip, ti fajlovi ne postoje pa nemas
sta brisati -- samo raspakuj ovaj.

KORACI
------
1. Raspakuj preko root-a (prepisi fajlove).
2. Ako postoje, obrisi tri fajla gore (app/admin/postavke/* i lib/settings.ts).
3. npm run dev -> provjeri KM/€ prekidac u navbaru i da admin NEMA vise "Postavke".
4. git add -A && git commit -m "feat: KM/EUR prekidac (default marke), bez admin opcije" && git push
   (git add -A da uhvati i brisanje fajlova.)

NEMA prisma db push. Schema se ne mijenja.

Napomena: alat za prikaz slika mi je u ovoj sesiji u kvaru pa nisam mogao
vizuelno provjeriti izgled. TypeScript je cist. Baci pogled u npm run dev prije
push-a (posebno da prekidac ne stiska navbar na mobitelu).

POPRAVKA BUILDA — nedostajuće polje "street"
============================================

GREŠKA
------
  ./app/[locale]/kontakt/page.tsx:104
  Property 'street' does not exist on type '{ name; id; city }'

UZROK (moja greška)
-------------------
Kad sam lokacije prebacio iz koda u bazu, zamijenio sam staru listu LOCATIONS
(koja je imala naziv, ulicu i grad) funkcijom getActiveLocations. Ta funkcija
je bila napravljena za padajući izbornik pri rezervaciji, gdje trebaju samo
id i naziv, pa je dohvatala samo id, naziv i grad.

Podnožje, kontakt stranica i sekcija lokacija trebaju i ulicu.

POPRAVLJENO
-----------
1) getActiveLocations sada dohvata i ulicu i poštanski broj. Padajući izbornik
   ta polja jednostavno ignoriše, pa se ništa drugo ne mijenja.

2) Usput sam našao još jedan propust: komponenta "Lokacije" na naslovnoj
   NIJE bila prevezana, nego je i dalje čitala staru listu iz koda. Znači
   promjena lokacije u adminu ne bi se vidjela na naslovnoj. Sada prima
   podatke iz baze kao i ostale.

PROVJERENO
----------
Uporedio sam polje po polje šta svaka komponenta traži i šta funkcija vraća:
  Footer              -> naziv, ulica, grad     OK
  Kontakt stranica    -> naziv, ulica, grad     OK
  O nama              -> naziv                  OK
  Lokacije (naslovna) -> naziv, ulica, grad     OK
  Obrazac rezervacije -> id, naziv              OK
Hardkodirana lista LOCATIONS se više nigdje ne koristi.

ZAŠTO MI JE PROMAKLO, I ŠTA MIJENJAM
------------------------------------
U mom okruženju Prisma klijent se ne može generisati (nema pristupa
njihovom serveru), pa TypeScript sve podatke iz baze vidi kao "bilo šta" i
ovakve greške ne prijavljuje. Pokušao sam to zaobići, ali provjera ne hvata
baš ovu vrstu greške.

Zato: prije svakog pusha pokreni

    npm run build

To je jedina pouzdana provjera i traje minut. Bolje da pukne kod tebe nego
na Vercelu.

FAJLOVI
-------
  lib/fleet-data.ts            (dohvata i ulicu)
  components/home/Locations.tsx (prima podatke iz baze)
  app/[locale]/page.tsx         (prosljeđuje lokacije)

Schema se NE mijenja.

KORACI
------
1. Raspakuj preko root-a projekta.
2. npm run build          <-- mora proći
3. npm run dev -> provjeri podnožje, /kontakt i sekciju lokacija na naslovnoj
4. git add -A
   git commit -m "fix: lokacije iz baze nose i adresu, sekcija Lokacije prevezana"
   git push

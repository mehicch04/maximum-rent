MAXIMUM RENT A CAR — cistka desktop dijagnostike (3 rijeseno + 1 iskreno)
========================================================================

1) "Unused preconnect"  -> RIJESENO
   [app/[locale]/page.tsx, app/[locale]/vozila/page.tsx]
   Dodao sam ranije preconnect na Supabase, ali slike idu kroz next/image
   (Vercel proxy /_next/image), a NE direktno sa supabase.co -> browser nikad
   ne otvara vezu ka Supabase, pa je preconnect bio beskoristan (i PageSpeed ga
   je zato flagovao). Uklonjen s obje stranice.

2) "Legacy JavaScript" (12 KiB)  -> RIJESENO
   [package.json -> browserslist]
   Polyfilli (Array.at, Object.hasOwn, itd.) su se ubacivali zbog preblagog
   browserslist-a. Postavljen moderni target:
     chrome>=93, edge>=93, firefox>=93, safari>=15.4, ios_saf>=15.4, not dead
   Svi browseri od ~2022. imaju te funkcije nativno, pa polyfilli nestaju.
   TRADE-OFF: ispadaju browseri stariji od ~2022 (npr. iPhone koji ne moze
   preko iOS 15.3). U 2026. to je zanemarivo za rent-a-car, ali ako zelis siru
   podrsku, vrati stari browserslist.

3) "Improve image delivery" (128 KiB)  -> RIJESENO (za naslovnu)
   [CarGallery/CarCard/FleetGrid + app/[locale]/page.tsx]
   Slike na naslovnoj su se servirale kao 640px iako se prikazuju ~171px, jer
   je "sizes" bio prevelik (31vw). Sada featured sekcija na naslovnoj koristi
   manji sizes (20vw na desktopu) -> next/image bira manji kandidat (256/384).
   Na /vozila su kartice vece pa tamo ostaje kako je bilo (nije dirano).

4) "Render-blocking requests" (~90ms)  -> NIJE POPRAVLJIVO IZ KODA (iskreno)
   To su Next-ovi CSS chunkovi koje App Router ubacuje kao render-blocking po
   dizajnu. 90ms je uglavnom latencija kriticnog puta na sitnim fajlovima. Ne
   moze se ukloniti bez zaobilaznica koje lome stil, a i "Unscored" je.

Sve ove stavke su ionako "Unscored" (ne obaraju Performance ocjenu), ali 1-3 su
sada cisti u izvjestaju.

KORACI
------
1. Raspakuj preko root-a.
2. npm install   (da build pokupi novi browserslist; Vercel svakako rebuilda)
3. npm run dev -> desktop: DevTools Network, provjeri da NEMA veze ka
   supabase.co i da se slike na naslovnoj servisaju manje (256/384, ne 640).
4. git add . && git commit -m "perf(desktop): ukloni unused preconnect, moderni browserslist, manji featured image sizes" && git push
5. Ponovo PageSpeed (desktop) -> "Unused preconnect", "Legacy JS" i vecina
   "image delivery" bi trebali nestati.

Napomena: alat za prikaz slika mi je u kvaru pa nisam vizuelno provjerio, ali TS
je cist. Baci pogled da slike na naslovnoj i dalje izgledaju ostro (manji sizes
je i dalje 2x+ ostriji od prikaza, pa bi trebalo biti ok).

POPRAVKA — aktivna rezervacija je ispadala iz aktivnih
=====================================================

Schema se NE mijenja. Samo: npm run build

ŠTA SE DEŠAVALO
---------------
Uredite rezervaciju kojoj je vozilo već izdato, sačuvate, i ona se vrati
među potvrđene iako je auto i dalje kod klijenta.

UZROK
-----
Izbornik statusa u obrascu nije imao opciju "U toku". Kad se otvori aktivna
rezervacija, izbornik nije mogao prikazati njeno stvarno stanje, pa je pri
spremanju poslao neku drugu vrijednost.

Server je imao isti propust: u popisu dozvoljenih statusa "U toku" nije
postojao, pa ga ne bi ni prihvatio da je poslan.

POPRAVLJENO
-----------
Status "U toku (vozilo kod klijenta)" sada postoji i u izborniku i na
serveru. Kad uređujete aktivnu rezervaciju, izbornik pokazuje njeno stvarno
stanje i ona OSTAJE aktivna nakon spremanja.

Ako je želite vratiti u potvrđene, to i dalje možete: samo odaberite drugi
status u izborniku. Razlika je što se sada to dešava kad vi tako odlučite, a
ne samo od sebe.

UPOZORENJE PRI VRAĆANJU UNAZAD
------------------------------
Ako aktivnu rezervaciju vratite u potvrđene, kontaktirane ili nove, iskoči
narandžasto upozorenje:

  "Vraćate najam koji je već u toku. Vozilo je izdato i vodi se kod klijenta.
   Ovo mijenjajte samo ako je izdavanje zabilježeno greškom."

Nije zabrana, samo napomena. Postoje slučajevi kad je izdavanje kliknuto
greškom i treba ga poništiti.

USPUT POPRAVLJENO
-----------------
Provjera sudara pri uređivanju gledala je samo potvrđene rezervacije. Sada
obuhvata i one u toku, pa se vozilo koje je kod klijenta ne može dodijeliti
nekom drugom kroz obrazac za uređivanje.

Provjerio sam i da se popis opcija u obrascu i popis dozvoljenih statusa na
serveru potpuno poklapaju, jer je upravo njihov nesklad i bio uzrok.

PROVJERENO
  aktivna, ništa se ne dira        -> ostaje aktivna
  aktivna, namjerno u potvrđene    -> prelazi, uz upozorenje
  aktivna -> završeno              -> prelazi
  potvrđena -> u toku              -> prelazi
  podmetnuta nepostojeća vrijednost -> zadržava se postojeći status

FAJLOVI
-------
  components/admin/EditInquiryForm.tsx  (opcija i upozorenje)
  app/admin/edit-actions.ts             (dozvoljeni statusi, provjera sudara)

KORACI
------
1. Raspakuj preko root-a projekta.
2. npm run build
3. npm run dev -> /admin -> filter "Aktivne"
   - uredi aktivnu rezervaciju i sačuvaj bez diranja statusa
   - mora ostati u tabu "Aktivne"
   - zatim probaj namjerno prebaciti u "Potvrđeno" i provjeri upozorenje

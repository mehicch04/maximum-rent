POPRAVKA BUILDA — kanal MANUAL nedostaje u bazi
===============================================

*** OBAVEZNO: npx prisma generate && npx prisma db push ***

GREŠKA
------
  Type '"MANUAL"' is not assignable to type 'InquiryChannel | undefined'

UZROK (moja greška)
-------------------
Rezervacije imaju polje "kanal" s vrijednostima EMAIL i WHATSAPP. Za
manuelne rezervacije treba i treća, MANUAL.

Ja sam tu vrijednost dodao u svojoj kopiji scheme dok sam radio, pa je
kasnije pročitao i zaključio da već postoji u projektu. Na osnovu toga sam
napisao da se schema ne mijenja i nisam je uključio u zip.

Kod je tako otišao tražeći vrijednost koje u bazi nema.

POPRAVKA
--------
U schemi je sada:

    enum InquiryChannel {
      EMAIL
      WHATSAPP
      MANUAL
    }

DVIJE MOGUĆNOSTI KAKO PRIMIJENITI
---------------------------------
A) Raspakuj ovaj zip (zamjenjuje prisma/schema.prisma) pa pokreni migraciju.
   Ovo je u redu ako schemu nisi mijenjao sam.

B) Ako si schemu i sam dopunjavao, NEMOJ prepisivati fajl. Umjesto toga
   otvori prisma/schema.prisma, nađi:

       enum InquiryChannel {
         EMAIL
         WHATSAPP
       }

   i dodaj MANUAL kao treću vrijednost. Pa pokreni migraciju.

Postojeći zapisi se ne diraju: dodavanje nove vrijednosti u popis ne mijenja
one koji već postoje.

KORACI
------
1. Primijeni A ili B odozgo.
2. npx prisma generate
3. npx prisma db push
4. npm run build          <-- mora proći
5. git add -A
   git commit -m "fix(schema): dodaj MANUAL kanal za manuelne rezervacije"
   git push

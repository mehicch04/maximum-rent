POPRAVKA BUILDA — readonly niz u upitu
======================================

Schema se NE mijenja. Samo: npm run build

GREŠKA
------
  Type 'readonly ["CONFIRMED", "IN_PROGRESS"]' is readonly and cannot be
  assigned to the mutable type 'InquiryStatus[]'

UZROK
-----
Popis statusa u novom uvjetu za flotu napisao sam s oznakom "as const".
Ta oznaka niz čini nepromjenjivim, a Prisma na tom mjestu prima samo
običan niz i odbija nepromjenjivi.

Isti popis se drugdje u istom fajlu koristi ISPRAVNO, kroz raspakivanje:

    status: { in: [...EARNING] }

Ja sam ovdje napisao "as const" direktno u upitu i propustio to
raspakivanje.

POPRAVKA
--------
Popis je izdvojen u konstantu, kao i EARNING, i raspakuje se pri upotrebi:

    const HOLDING = ["CONFIRMED", "IN_PROGRESS"] as const;
    ...
    status: { in: [...HOLDING] }

Prošao sam kroz cijeli projekat i provjerio ima li još upita s
nepromjenjivim nizom. Nema ih.

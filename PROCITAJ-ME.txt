VRAĆANJE POPRAVLJENE ANALITIKE
==============================

Schema se NE mijenja. Samo: npm run build

ŠTA SE DESILO
-------------
Primijenili ste "maximum-povuceno-u-najmu" NAKON "maximum-readonly-fix".

Taj stariji paket u sebi nosi raniju verziju lib/analytics.ts, onu s
greškom. Kad ste ga raspakovali preko projekta, prepisao je popravljeni
fajl i greška se vratila.

NIJE GREŠKA DO VAS. Trebao sam vas upozoriti da su ta dva paketa već
sadržana u kumulativnom.

ŠTA NE TREBA PRIMJENJIVATI
--------------------------
  maximum-povuceno-u-najmu    već je unutar kumulativnog
  maximum-isteklo-odvojeno    već je unutar kumulativnog

Provjerio sam sadržaj svakog: kumulativni paket ima sve iz oba.

  iz "povuceno-u-najmu":  fleetWhere, oznaka "povučeno iz ponude",
                          živi status za povučena vozila
  iz "isteklo-odvojeno":  polje expiredAt, upis u noćnom poslu,
                          oznaka "Isteklo", prikaz u pregledu

REDOSLIJED KOJI JE ISPRAVAN
---------------------------
  1. maximum-kumulativna-popravka   (sve osim popravke tipa)
  2. maximum-readonly-fix           (popravka tipa)
  3. ovaj paket                     (isto što i readonly-fix)

Ovaj paket sadrži isti popravljeni lib/analytics.ts kao readonly-fix.
Ako ste readonly-fix već primijenili, dovoljno je raspakovati ovaj i
build će proći.

KORACI
------
1. Raspakuj preko root-a projekta.
2. npm run build          <-- mora proći
3. git add -A
   git commit -m "fix(analitika): vrati popravljeni uvjet flote"
   git push

Poslije ovoga nemate više ništa za primijeniti. Sve je unutra.

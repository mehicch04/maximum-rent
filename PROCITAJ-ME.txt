POPRAVKA KEŠA — dostupnost se sada osvježava odmah
==================================================

Schema se NE mijenja. Samo: npm run build

PROBLEM
-------
Lista vozila i lista opreme na javnom sajtu čuvaju se u kešu pet minuta.
Četiri akcije koje mijenjaju zauzetost taj keš nisu poništavale, nego su
osvježavale samo admin stranicu.

Posljedica: potvrdiš rezervaciju, a sajt do pet minuta i dalje nudi to
vozilo kao slobodno. Gost pošalje upit za auto koji je već dat, i to se
otkrije tek kad ga pokušaš potvrditi.

Rezervacija se time nije mogla dvostruko napraviti, jer server ionako
provjerava sve prije upisa. Ali gost bi vidio pogrešnu ponudu i uzalud
poslao upit.

POPRAVLJENO
-----------
  confirmInquiry       potvrda rezervacije
  cancelInquiry        otkazivanje
  addBlock             blokada vozila
  removeBlock          uklanjanje blokade

Sve četiri sada poništavaju i "fleet" i "extras" keš, uz postojeće
osvježavanje admin stranice.

Uz to sam dopunio i dvije koje su imale samo "fleet":
  updateInquiry        uređivanje rezervacije
  createManualInquiry  nova manuelna rezervacija

Oprema se mijenja zajedno s rezervacijom, pa i njena lista mora pasti.

PROVJERA
--------
Prošao sam kroz sve serverske akcije u adminu i izdvojio one koje mijenjaju
zauzetost vozila ili opreme. Njih je šest i sve sada poništavaju oba keša:

  confirmInquiry        fleet + extras
  cancelInquiry         fleet + extras
  addBlock              fleet + extras
  removeBlock           fleet + extras
  updateInquiry         fleet + extras
  createManualInquiry   fleet + extras

ŠTA NAMJERNO NISAM DIRAO
------------------------
Javna ruta za upite (app/api/inquiries/route.ts) ne poništava keš, i tako
treba. Novi upit ima status "Novo" i ne zauzima ni vozilo ni opremu dok ga
ne potvrdiš, pa nema šta osvježavati.

FAJLOVI
-------
  app/admin/actions.ts                  (četiri funkcije)
  app/admin/edit-actions.ts             (dodan extras)
  app/admin/new-reservation-actions.ts  (dodan extras)

KORACI
------
1. Raspakuj preko root-a projekta.
2. npm run build
3. npm run dev
   - potvrdi rezervaciju u adminu
   - odmah otvori /vozila za taj period u drugom tabu
   - vozilo se više ne smije nuditi, bez čekanja

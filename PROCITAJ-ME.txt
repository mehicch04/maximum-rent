MAXIMUM RENT A CAR — smanjen crveni sjaj
========================================

ŠTA JE BILO
-----------
Crvena sjena ispod dugmadi i kartica bila je definisana kao
    0 8px 30px -8px  uz 45% neprovidnosti

To je zamućenje od 30 piksela, pa se crvena širila oko 7 piksela izvan ivice
elementa. Odatle onaj dojam da boja curi i da se prelijeva.

ŠTA JE SADA
-----------
    0 6px 20px -6px  uz 30% neprovidnosti

  doseg izvan ivice:  7px  ->  4px    (43% manje)
  jačina:             45%  ->  30%    (33% manje)
  ukupno oko 62% manje vidljiva sjena

Sjena i dalje postoji i element i dalje "stoji" iznad podloge, samo crvena
više ne izlazi izvan dugmeta.

Namjerno je nisam uklonio potpuno. Prvo sam probao jače smanjenje (doseg na
1px), ali je tada sjena praktično nestala i dugmad su izgledala plosnato.

USPUT
-----
Isti tip efekta stajao je i iza aktivne ikone u sekciji "Kako funkcioniše"
(crveni krug ispod ikone). Smanjen s 20% na 10%, da se uklopi.

ŠTA NISAM DIRAO
---------------
  - Crveni prsten oko odabrane sličice u svadbenoj galeriji: to nije ukras
    nego oznaka koja je slika izabrana.
  - Crveni okvir pri kliku u polja obrasca: to je oznaka fokusa i potrebna
    je za pristupačnost i rad tastaturom.

FAJLOVI
-------
  tailwind.config.ts            (definicija sjene)
  components/home/HowItWorks.tsx (halo iza ikone)

KORACI
------
1. Raspakuj preko root-a projekta.
2. npm run dev -> pogledaj dugmad na naslovnoj i kartice vozila
3. npm run build
4. git add -A
   git commit -m "ui: smanji crveni sjaj na dugmadi i karticama"
   git push

IZDAVANJE VOZILA — evidencija početka najma
===========================================

*** SCHEMA SE MIJENJA: prisma generate && prisma db push ***

ŠTA JE DODANO
-------------
Na rezervacijama sa statusom "Potvrđeno" pojavljuje se dugme
"Izdaj vozilo". Klik otvara pitanje "Potvrdite izdavanje vozila klijentu?"
s podacima gosta i vozila.

Potvrdom se:
  - u bazu upisuje trenutno vrijeme kao STVARNO preuzimanje
  - status mijenja u "U toku"

Agovoreno vrijeme preuzimanja ostaje netaknuto. Gost koji dođe dva sata
kasnije ne smije tiho prepisati ono što je rezervisano, a razlika između
dogovorenog i stvarnog je podatak koji kasnije vrijedi imati.

NAJVAŽNIJI DIO POSLA NIJE DUGME
-------------------------------
Statusa "U toku" u sistemu nije bilo. Osamnaest mjesta u kodu držalo je
vozilo zauzetim samo ako je rezervacija "Potvrđena".

Da sam dodao novi status bez toga, dogodilo bi se ovo: izdaš vozilo gostu,
ono odmah postane "U toku", i u tom trenutku sistem ga prestane smatrati
zauzetim. Sajt bi ga ponovo nudio, a admin bi dozvolio novu rezervaciju za
isti termin. Auto koji je fizički kod gosta bio bi ponuđen drugome.

Zato sam prošao kroz sva mjesta i provjerio svako:

  javna pretraga vozila            prepoznaje "U toku"    OK
  zauzetost vozila i opreme        prepoznaje             OK
  prihod i iskoristivost           prepoznaje             OK
  izdata oprema u adminu           prepoznaje             OK
  provjera sudara pri potvrdi      prepoznaje             OK
  provjera sudara pri izmjeni      prepoznaje             OK
  provjera sudara kod nove         prepoznaje             OK

Namjerno JEDINO na ekranu Ugovori nije dodano: tamo se prikazuju
nadolazeća preuzimanja, a vozilo koje je već izdato ne treba novi ugovor.

OSTALO
------
  - Oznaka "U toku" u listi rezervacija, u brend crvenoj.
  - Ako se pokuša izdati nešto što nije potvrđeno (već izdato, otkazano,
    neodobreno), server to odbija uz poruku. Dugme se ionako ne prikazuje,
    ali zahtjev se može poslati i mimo njega.

KORACI
------
1. Raspakuj preko root-a projekta.
2. npx prisma generate
3. npx prisma db push
4. npm run build
5. npm run dev -> /admin
   - na potvrđenoj rezervaciji klikni "Izdaj vozilo" i potvrdi
   - status mora preći u "U toku"
   - OBAVEZNO PROVJERI: otvori /vozila na sajtu za taj isti period,
     vozilo se i dalje NE SMIJE nuditi

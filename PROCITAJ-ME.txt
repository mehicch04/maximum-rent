MAXIMUM RENT A CAR — dvije valute (KM i €) + admin izbor primarne valute
========================================================================

KLJUCNO: marka je ZAKONSKI fiksno vezana za euro: 1 EUR = 1.95583 KM.
Zato NEMA zivog kursa ni API-ja — konverzija je konstanta i uvijek tacna.

STA JE DODANO
-------------
1) Prekidac valute (KM / €) u vrhu sajta (navbar). Posjetilac klikne i SVE
   cijene se odmah preracunaju. Izbor se pamti (localStorage).
2) Cijene se i dalje UNOSE u markama u adminu. Prikaz u eurima se racuna
   automatski i ZAOKRUZUJE (npr. 110 KM -> 56 €).
3) Admin postavka primarne valute: /admin/postavke (novi tab "Postavke").
   Vlasnik bira da li se sajtu podrazumijevano prikazuje KM ili € (posjetilac
   svejedno moze prebaciti). Cuva se u bazi.

KAKO RADI (ukratko)
-------------------
- Cijene su u bazi u KM (kao i do sada).
- lib/currency.ts radi konverziju (fiksni kurs) + zaokruzivanje + format.
- CurrencyProvider drzi trenutnu valutu; pocetna = admin postavka; posjetilac
  je mijenja preko CurrencySwitch u navbaru.
- Price komponenta prikazuje bilo koji KM iznos u odabranoj valuti.
- Kartica auta (CarCard) sada koristi <Price/> umjesto fiksnog "KM".

*** SCHEMA SE PROMIJENILA -> OBAVEZNO: ***
  npx prisma generate
  npx prisma db push        (kreira tabelu Setting — nedestruktivno)

Napomena: schema.prisma mozda sadrzi i model AdminLoginAttempt (iz ranijeg
security fix-a). Ako ga vec imas, sve je isto; ako nemas, samo se kreira jos
jedna prazna tabela — bezopasno.

KORACI
------
1. Raspakuj preko root-a.
2. npx prisma generate && npx prisma db push
3. npm run dev  -> u navbaru probaj KM/€; na /admin/postavke promijeni primarnu
   valutu i provjeri da se default na sajtu promijenio.
4. git add . && git commit -m "feat: KM/EUR prekidac + admin primarna valuta (fiksni kurs)" && git push

VAZNO (testiranje)
------------------
Alat za prikaz slika mi je u ovoj sesiji bio u kvaru pa NISAM mogao vizuelno
provjeriti izgled. TypeScript je cist i sve je wire-ovano po tvom postojecem
kodu, ali molim te pokreni "npm run dev" i baci pogled prije push-a:
  - prekidac KM/€ u navbaru (i na mobitelu da ne stiska)
  - cijena na kartici se mijenja i zaokruzuje
  - /admin/postavke cuva izbor
Ako nesto ne stima (razmak u navbaru, zaokruzivanje na .5 umjesto na cijeli
broj, itd.) javi — lako se stela.

ZAOKRUZIVANJE
-------------
Trenutno zaokruzujem na CIJELI broj (110 KM -> 56 €). Ako zelis na 2 decimale
(56.24 €) ili na najblizih 5, promjena je jedna linija u lib/currency.ts
(funkcija displayAmount) — javi.

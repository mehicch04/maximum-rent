OPREMA — zašto puca i zašto u obrascu nema ničega
=================================================

KRATAK ODGOVOR
--------------
Tabele za opremu još ne postoje u bazi. Nije pokrenut `prisma db push`.

Build je prošao jer `prisma generate` sređuje samo TIPOVE u kodu.
`prisma db push` je zaseban korak koji mijenja STVARNU bazu — kreira tabele.

POKRENI OVO U FOLDERU PROJEKTA
------------------------------
    npx prisma generate
    npx prisma db push

Nakon toga /admin/oprema radi, unesi par stavki i pojavit će se u obrascu
za upit.

ZAŠTO SU SIMPTOMI RAZLIČITI
---------------------------
  - Javna strana (obrazac za upit) IMA zaštitu: ako tabele nema, vrati praznu
    listu i sekcija se tiho sakrije. Zato tamo "nema ničega", a sajt radi.
  - Admin strana je NIJE imala: upit je pukao i dobio si "Application error".

To je bio propust u mojoj isporuci — admin je trebao imati istu zaštitu.

ŠTA JE U OVOM ZIPU
------------------
  - /admin/oprema više ne puca. Ako tabele nema, prikaže jasnu poruku
    s tačnim komandama koje treba pokrenuti.
  - Spremanje stavke je također zaštićeno: ako baza nije spremna, dobiješ
    poruku umjesto pada stranice.

ČEMU SLUŽI STRANICA /admin/oprema
---------------------------------
To je katalog dodatne opreme koju nudiš uz najam. Ti tu definišeš ŠTA gost
može zatražiti; gost to onda vidi u obrascu za upit i označi šta mu treba.

Za svaku stavku postavljaš:
  - naziv i napomenu na HR i EN
  - kako se naplaćuje: po danu / jednokratno / uključeno u cijenu
  - cijenu u markama
  - najveću količinu (1 = kvačica, više = brojač, npr. 3 sjedalice)
  - redoslijed i prikaži/sakrij

Bez unesenih stavki sekcija se u obrascu NE prikazuje — što je i ispravno,
da gost ne gleda prazan okvir.

PRIJEDLOG ZA POČETAK
--------------------
  Dječija sjedalica (0–4)         po danu      3 kom
  Booster sjedalica (4–12)        po danu      3 kom
  Dodatni vozač                   uključeno    1
  Prelazak granice                po najmu     1
  GPS navigacija                  po danu      1
  Preuzimanje van radnog vremena  po najmu     1

KORACI
------
1. Raspakuj preko root-a projekta.
2. npx prisma generate
3. npx prisma db push
4. npm run dev -> /admin/oprema -> unesi stavke -> provjeri obrazac za upit
5. git add -A
   git commit -m "fix(admin): oprema ne puca kad tabela ne postoji"
   git push
